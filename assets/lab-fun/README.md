# Lab fun photos

Add public lab fun photos here as optimized `.webp` or `.jpg` files.

Recommended:
- Use descriptive lowercase filenames, for example `cell-culture-day.webp`.
- Resize large photos before committing; around 1600 px wide is usually enough.
- Keep each image roughly under 500 KB when possible.
- Add meaningful alt text when wiring images into the site data.
